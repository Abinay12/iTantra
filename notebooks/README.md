# iTantra Notebooks

This directory is designated for interactive experiments, exploratory data analysis, and performance benchmarking.

## Planned Notebooks:
1. `01_channel_simulation_demo.ipynb`:
   - SNR vs. Symbol Error Rate (SER) and Mean Squared Error (MSE) under AWGN and Rayleigh fading.
   - Constellation diagrams and power normalization visualization.
2. `02_multilingual_speech_pipeline.ipynb`:
   - Audio waveform and Mel filterbank feature inspection for Telugu, Hindi, Tamil, Bengali, and Marathi.
   - End-to-end latency and reconstruction evaluation on CPU.
3. `03_radio_packetization_and_sdr.ipynb`:
   - Packet framing, CRC corruption rate under varying SNR conditions, and baseband SDR streaming analysis.
